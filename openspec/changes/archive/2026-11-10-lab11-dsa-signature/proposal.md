# Proposal

## Why
Выполнить лабораторную №11: электронная подпись DSA (FIPS 186) любого файла и отдельная проверка. Задание: `lectures/Лабораторные работы ЗИ.pdf`, физическая страница 5. Лекция 8, страницы 50–57, проверена по изображениям.

## What Changes
- Реализовать формулы DSA (FIPS 186) в common/crypto.hpp и common/crypto.cpp.
- Использовать общий файловый слой и меню labs/lab09–11; MD5 из course_files/md5.hpp, отдельные ключи и подпись.
- Добавить ручной пример, генерацию, тесты, README и подробный local/reports/lab11.md.
- Обновить прогресс; лабораторные 5–8 пока пропустить.

## Capabilities
### New Capabilities
- `dsa-signature`: учебная подпись DSA (FIPS 186), создание и проверка файловых подписей.
### Modified Capabilities
Нет: прежние математические контракты сохраняются.

## Impact
C++20 и стандартная библиотека, сборка g++, без зависимостей. Общий код не копируется. PDF и существующие файлы пользователя сохраняются.
