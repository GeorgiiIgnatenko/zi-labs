# Design

## Context
Задание №11 разрешает хеш не слабее MD5 и отдельный файл подписи. Лекция 8 задаёт формулы DSA (FIPS 186); числовой пример: p=67,q=11,a=25,x=6,h=3,k=8 → r=2,s=6.

## Goals / Non-Goals
Реализовать математическую схему и весь файловый цикл. Это учебная модель с p<=2000000000, а не совместимый с промышленными стандартами криптопровайдер. Длинная арифметика, стандартизированные контейнеры и сертификаты не вводятся.

## Decisions
- В common/crypto.* находятся формулы, проверка параметров, ключи и генерация k. common/signature_files.* читает бинарные файлы блоками 65536 байтов, использует существующий MD5 и сохраняет отдельные текстовые ключи/подписи; common/signature_app.* содержит меню и CLI.
- У Эль-Гамаля q=0, простое p>=5, первообразный g, 1<x,k<p-1, gcd(k,p-1)=1; s=0 допустимо. ГОСТ/DSA: простые p,q, 3<=q<p, q делит p-1, g>1 и g^q=1, 0<x,k<q, 0<r,s<q. Нулевые r/s требуют нового k. Случайный выбор ограничен 4096 попытками, чтобы вырожденные ручные параметры не зациклили программу.
- Генерация использует p=2q+1 из библиотеки DH, для подгруппы g_DH^2. Простота проверяется точно, тест Ферма не подменяется и не меняется.
- Полный MD5 трактуется как 32 hex-цифры слева направо; остаток вычисляется по цифрам, без переполнения. Для Эль-Гамаля h=2+H mod(p-2), чтобы соблюсти 1<h<p лекции; для ГОСТ h=H mod q, ноль заменяется на 1; для DSA h=H mod q, ноль разрешён. Это документированное учебное преобразование, не стандартное усечение хеша FIPS.
- Отдельные файлы ZISIG-PRIVATE-1 / ZISIG-PUBLIC-1 и ZISIG-1 содержат алгоритм. Подпись содержит только r,s; ни x,k, ни доверенный хеш в ней не хранятся. Открытый ключ проверяющий получает отдельно. Исходный файл читается без изменений.
- Существующие выходные пути и ссылки отклоняются; частичные новые результаты удаляются при ошибке. Секретный ключ получает права владельца rw. Это обычный локальный файловый интерфейс, без гарантий атомарности при конкурентных изменениях путей.
- Все произведения остатков меньше 4e18; суммы сокращённых остатков меньше 4e9. Произведения трёх чисел не вычисляются. h*16+digit меньше 3.2e10. long long достаточно; старый предел библиотеки сохраняется.

## Risks / Trade-offs
MD5 и малые параметры предназначены для задания. Коллизии полного MD5 и дополнительного сокращения возможны: нельзя обещать обнаружение любого изменения. mt19937_64 не криптографический генератор. Секретный файл хранится открытым текстом. Числовые h=3 из лекции не подменяют MD5 файлов.
