# Proposal

## Why

Нужно выполнить лабораторную №2 со страницы 2 файла `lectures/Лабораторные работы ЗИ.pdf`: найти x в `a^x mod p = y` методом «шаг младенца, шаг великана». Библиотека первой лабораторной уже содержит степень по модулю, НОД и генерацию чисел.

## What Changes

- Добавить в общую библиотеку дискретный логарифм по алгоритму лекции 1, страницы 58–65.
- Предусмотреть ручной ввод и генерацию разрешимого примера внутри функции.
- Различать найденное решение, отсутствие решения и нарушение условий алгоритма.
- Создать `labs/lab02/` по прежнему макету, проверки и подробный `local/reports/lab02.md`.
- Сохранить проверенную работоспособность лабораторной №1, обновить инструкции и прогресс.

## Capabilities

### New Capabilities

- `discrete-log`: поиск наименьшего неотрицательного дискретного логарифма при взаимно простых a,p и демонстрация алгоритма.

### Modified Capabilities

Нет: контракты функций первой лабораторной сохраняются.

## Impact

Дополняются `common/crypto.hpp`, `common/crypto.cpp`, README и прогресс OpenSpec. Добавляются меню, тесты и отчёт второй лабораторной. Стандарт C++20, числовой предел, способ сборки и исходные PDF не меняются.
