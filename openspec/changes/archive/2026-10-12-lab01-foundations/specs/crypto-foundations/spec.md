# Spec Delta

## Purpose

Обеспечить математические функции и демонстрацию лабораторной №1 по защите информации с понятным кодом и безопасной арифметикой для чисел порядка 10^9.

## ADDED Requirements

### Requirement: Быстрое возведение в степень
Библиотека SHALL вычислять `a^x mod p` целочисленным алгоритмом за O(log x) при `|a| <= 2000000000`, `0 <= x <= 2000000000`, `1 <= p <= 2000000000` без переполнения промежуточных произведений.

#### Scenario: Пример из лекции
- **WHEN** переданы `a=3`, `x=100`, `p=7`
- **THEN** результат равен 4.

#### Scenario: Граничные значения
- **WHEN** показатель равен 0, включая основание 0
- **THEN** результат равен `1 mod p`; при `p=1` результат 0.

#### Scenario: Большое произведение
- **WHEN** переданы `a=1999999999`, `x=2`, `p=2000000000`
- **THEN** результат равен 1 без переполнения.

### Requirement: Тест Ферма
Библиотека SHALL проверять вероятную простоту тестом Ферма с проверкой НОД и 100 случайными основаниями по умолчанию; успешный ответ MUST трактоваться как вероятная простота. Неположительное число раундов MUST отклоняться.

#### Scenario: Малые числа
- **WHEN** проверяются числа меньше 2, числа 2 и 3, чётные числа больше 2
- **THEN** результаты соответственно false, true, false без некорректного случайного диапазона.

#### Scenario: Свидетель составности
- **WHEN** выбранное основание имеет НОД больше 1 с n или нарушает сравнение Ферма
- **THEN** функция возвращает false.

#### Scenario: Все раунды пройдены
- **WHEN** 100 выбранных оснований проходят проверки
- **THEN** функция возвращает true, а меню сообщает «вероятно простое» без гарантии доказанной простоты.

### Requirement: Расширенный алгоритм Евклида
Библиотека SHALL возвращать неотрицательный НОД и целые x, y с `a*x+b*y=НОД` для `|a|, |b| <= 2000000000`.

#### Scenario: Проверка коэффициентов
- **WHEN** переданы 28 и 19
- **THEN** возвращаются НОД=1, x=-2, y=3, удовлетворяющие равенству Безу.

#### Scenario: Нули и знаки
- **WHEN** переданы нули или отрицательные значения
- **THEN** равенство Безу сохраняется; для (0,0) принято (НОД,x,y)=(0,1,0).

### Requirement: Режимы ввода и генерации
Программа SHALL обеспечивать ручной ввод a,b и генерацию внутри функции как произвольных положительных чисел, так и вероятно простых чисел с вызовом теста Ферма. Программа SHALL показывать исходные числа, НОД, коэффициенты и проверку равенства.

#### Scenario: Генерация пары
- **WHEN** выбран пункт 4 либо 5
- **THEN** функция генерирует a,b в [1,2000000000] либо [2,2000000000] с отбором по Ферма соответственно, вычисляет и выводит результат Евклида.

### Requirement: Ошибочные данные
Библиотека SHALL отвергать выход за объявленные границы через `std::invalid_argument`, а меню SHALL повторять запрос при некорректном вводе.

#### Scenario: Ошибка строки
- **WHEN** введены буквы, дробь, лишние символы или число вне диапазона
- **THEN** меню объясняет допустимый диапазон и снова запрашивает число.

#### Scenario: Конец ввода
- **WHEN** входной поток закончился
- **THEN** программа завершает работу без бесконечного повторения ошибок.
