# Proposal

## Why

Нужно выполнить лабораторную №1 со страницы 1 файла `lectures/Лабораторные работы ЗИ.pdf` и подготовить понятную основу для остальных лабораторных. Исходная папка содержит только лекции и четыре примера без содержательных имён.

## What Changes

- Общая библиотека C++20: степень по модулю, тест Ферма, расширенный Евклид.
- Консольное меню с ручными и сгенерированными данными, проверкой результата.
- Поддержка чисел порядка 10^9 с явными безопасными границами.
- Единый простой макет, исправление имён и расширений примеров курса.
- Подробные отчёты в игнорируемой `local/`, локальный Git и сохранение контекста в OpenSpec.

## Capabilities

### New Capabilities

- `crypto-foundations`: математические функции и режимы первой лабораторной.
- `lab-workflow`: единый макет, локальные отчёты и сохранение прогресса.

### Modified Capabilities

Нет: это первая работа в репозитории.

## Impact

Добавляются `common/`, `labs/lab01/`, `templates/`, `openspec/`, `AGENTS.md`, `.gitignore`. Примеры в `course_files/` переименовываются и минимально исправляются, PDF остаются без изменений. Новые зависимости для программы не нужны.
