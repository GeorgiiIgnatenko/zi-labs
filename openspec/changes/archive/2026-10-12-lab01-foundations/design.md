# Design

## Context

Первая лабораторная требует три функции, а следующие расширяют эту же библиотеку. Пользователь просит понятный университетский код без системы сборки. Точное требование к масштабу чисел — 10^9, проверено визуально в PDF.

## Goals / Non-Goals

**Goals:** реализовать задание, сделать воспроизводимую сборку и проверки, написать подробный локальный отчёт, сохранить правила и прогресс.

**Non-Goals:** реализовывать следующие лабораторные, добавлять графический интерфейс, длинную арифметику или промышленную криптографию.

## Decisions

- `common/crypto.hpp` содержит объявления, `.cpp` — реализации. Каждая лабораторная имеет отдельный `main.cpp`; компиляция одной командой.
- Числа и коэффициенты — `long long`; предел 2 000 000 000. Произведение остатков меньше 4×10^18, помещается в signed 64-bit. Проверка диапазона выполняется до смены знака и арифметики.
- Степень вычисляется справа налево за O(log x). Основание нормализуется, `1 % p` обрабатывает модуль 1. Для показателя 0 используется соглашение `a^0 = 1`, включая `0^0`.
- Евклид использует строки U, V, T как на странице 53 лекции 1. Знаки коэффициентов восстанавливаются после работы с абсолютными значениями.
- Тест Ферма выполняет до 100 раундов, проверяет НОД и сравнение `a^(n-1) mod n = 1`. Основания выбираются независимо из [2, n-2], повторения разрешены. 2 и 3 обрабатываются отдельно.
- Случайные пары генерируются внутри `generate_gcd_example`; вероятно простые числа отбираются `generate_probable_prime` через тест Ферма.
- Генератор `mt19937_64` инициализируется один раз. Отдельные тесты используют фиксированный seed для воспроизводимых входов.
- Числа читаются по строкам, чтобы отвергать дроби, буквы, переполнение и лишние символы. EOF завершает работу без цикла ошибок.
- `local/` и `build/` игнорируются; в Git сохраняются правила, шаблон отчёта и прогресс, сам отчёт остаётся локальным.
- OpenSpec инициализирован с `--tools none`; контекст задаётся `config.yaml`, а обязательное чтение файлов — корневым `AGENTS.md`.

## Risks / Trade-offs

- Числа Кармайкла могут пройти Ферма: вывод только «вероятно простое»; универсальная вероятность ошибки для всех входов не заявляется.
- `mt19937_64` служит учебной генерации, не реальным криптографическим ключам.
- Текущий предел нельзя просто увеличить без пересмотра умножения. Он достаточен для задания.
- Два сгенерированных числа могут совпасть: требование различия отсутствует; тогда НОД может равняться самому числу.
- Отчёты вне Git не восстанавливаются из клона; это пожелание пользователя, требуется отдельное резервное копирование.
