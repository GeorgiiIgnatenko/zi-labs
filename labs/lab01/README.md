# Лабораторная №1

Задание: [PDF, страница 1](../../lectures/Лабораторные%20работы%20ЗИ.pdf#page=1).

Реализованы:

1. `crypto::mod_pow(a, x, p)` — быстрое вычисление `a^x mod p`.
2. `crypto::fermat_prime(n)` — тест Ферма, 100 случайных оснований с проверкой НОД; 2 и 3 обрабатываются сразу.
3. `crypto::extended_gcd(a, b)` — НОД и коэффициенты `x, y`, удовлетворяющие `a*x + b*y = НОД`.
4. `crypto::generate_gcd_example(...)` — генерация пары чисел внутри функции, включая отбор через тест Ферма.

Код библиотеки находится в `common/`, здесь — только консольное меню и проверки.

## Запуск из корня репозитория

```sh
mkdir -p build
g++ -std=c++20 -Wall -Wextra -Wpedantic -O2 labs/lab01/main.cpp common/crypto.cpp -o build/lab01
./build/lab01
```

Для проверки примера из лекции выбрать `1`, ввести по строкам `3`, `100`, `7`; результат `4`.
Для Евклида выбрать `3`, ввести `28`, `19`; результат `НОД = 1, x = -2, y = 3`.
Пункты `4` и `5` генерируют данные. `0` завершает программу.

```sh
g++ -std=c++20 -Wall -Wextra -Wpedantic -O2 labs/lab01/tests.cpp common/crypto.cpp -o build/lab01_tests
./build/lab01_tests
```

## Границы

- `|a|, |b|, |n| <= 2 000 000 000`.
- Показатель `0 <= x <= 2 000 000 000`; модуль `1 <= p <= 2 000 000 000`.
- Для `p = 1` результат всегда `0`; для `x = 0` — `1 mod p`, в том числе при `a = 0` по принятому соглашению.
- Поддерживаются отрицательные `a, b`; НОД неотрицательный. Для `(0, 0)` возвращается `(0, 1, 0)`.
- Нарушение контракта библиотеки вызывает `std::invalid_argument`. Меню отклоняет неверный ввод и просит повторить его.
- Успешный тест Ферма не является доказательством простоты. Сгенерированные числа называются вероятно простыми; генератор случайных чисел учебный.
