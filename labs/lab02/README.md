# Лабораторная №2

Задание: [PDF, страница 2](../../lectures/Лабораторные%20работы%20ЗИ.pdf#page=2).
Теория: [лекция 1, страницы 54–65](../../lectures/Лекция%201%20ЗИ%202026.pdf#page=54).

Нужно найти x в уравнении `a^x mod p = y` алгоритмом «шаг младенца, шаг великана» (BSGS).

В общей библиотеке добавлены:

- `crypto::discrete_log(a, y, p)` — минимальное неотрицательное решение либо `std::nullopt`, если решения нет.
- `crypto::generate_discrete_log_example()` — генерация разрешимого примера внутри функции. Известный исходный показатель используется только для создания y; поиск получает a,y,p.

## Сборка и запуск из корня проекта

```sh
mkdir -p build
g++ -std=c++20 -Wall -Wextra -Wpedantic -O2 labs/lab02/main.cpp common/crypto.cpp -o build/lab02
./build/lab02
```

Меню: `1` — ручной ввод, `2` — генерация, `0` — выход.
Каждое число вводится на отдельной строке. Сначала запрашивается p, затем a и y.

Пример из лекции: выбрать `1`, ввести `23`, `2`, `9`. Ответ: `x = 5`, проверка `2^5 mod 23 = 9`.
Пример без решения: p=7, a=4, y=3. Степени 4 дают только остатки 1, 4, 2.

## Условия и результат

- `2 <= p <= 2 000 000 000`, `1 <= a < p`, `0 <= y < p`.
- Требуется `НОД(a,p)=1`. Простой p удовлетворяет этому при любом допустимом a. Составной p тоже разрешён при взаимной простоте.
- Для y=1 ответ x=0. Для y=0 решения нет при допустимом основании.
- Невзаимно простые a,p отвергаются как неподходящие для данного варианта BSGS; это не означает, что исходное уравнение не имеет решения.
- При генерации p проходит тест Ферма из лабораторной №1. Взаимная простота проверяется отдельно, поэтому корректность поиска не зависит от вероятностного ответа Ферма.
- Найденный показатель может быть меньше исходного: степени по модулю повторяются.

Используется вариант лекции: `m=floor(sqrt(p))+1`, таблица `y*a^j mod p`, поиск совпадения с `a^(im) mod p`, ответ `x=im-j`. `std::map` даёт `O(sqrt(p) log p)` операций с машинными числами и `O(sqrt(p))` памяти. Расхождение записи сложности в задании и лекции подробно объяснено в отчёте.
