# Лабораторная №3

Задание: [PDF, страница 2](../../lectures/Лабораторные%20работы%20ЗИ.pdf#page=2).
Схема и пример: [лекция 3, страницы 6–17](../../lectures/Лекция%203%20ЗИ%202026.pdf#page=6).

Два абонента получают общий ключ по схеме Диффи — Хеллмана:

```text
Y_A = g^X_A mod p        Y_B = g^X_B mod p
Z_A = Y_B^X_A mod p      Z_B = Y_A^X_B mod p
Z_A = Z_B.
```

Реализация находится в общей библиотеке. `diffie_hellman(p,g,x_a,x_b)` возвращает оба открытых значения и два независимо вычисленных общих ключа. `generate_diffie_hellman_parameters()` создаёт параметры внутри функции.

## Сборка и запуск из корня проекта

```sh
mkdir -p build
g++ -std=c++20 -Wall -Wextra -Wpedantic -O2 labs/lab03/main.cpp common/crypto.cpp -o build/lab03
./build/lab03
```

Меню: `1` — ручной ввод, `2` — генерация, `3` — пример лекции, `0` — выход.
При ручном вводе каждое число вводится на отдельной строке в порядке p, g, X_A, X_B.

Пример: p=23, g=5, X_A=7, X_B=13. Получаем Y_A=17, Y_B=21 и общий ключ 10.

## Параметры

- Простое `5 <= p <= 2 000 000 000`.
- Первообразный корень `2 <= g <= p-2`. Само g не обязано быть простым.
- Секреты `2 <= X_A,X_B <= p-1`, как в лекции. Для секрета p-1 открытое значение и общий ключ становятся 1 — это допустимый, но вырожденный учебный случай.
- При ручном вводе принимается любое подходящее простое p. При генерации выбирается p=2q+1, где p и q простые, p порядка 10^9.
- Простота проверяется точно отдельной `is_prime`, перебором делителей до корня. Вероятностная `fermat_prime` из первой лабораторной сохраняется без изменений.
- `is_primitive_root` проверяет порядок g по простым делителям p-1.

Программа моделирует обе стороны в одном процессе. Секреты показываются для учебного разбора; при самом обмене передаются Y_A и Y_B. Эта работа строит общее число, шифрование сообщений и сетевой обмен в неё не входят.
